# CLAUDE.md

Instruções para trabalhar neste repositório.

## Idioma

A partir de agora, todo **novo** commit message e **novo** comentário de código neste projeto deve ser escrito em **português do Brasil** — independente do idioma usado na conversa com o usuário.

- Não traduza retroativamente commits ou comentários já existentes (estão em inglês) — a regra vale só para o que for escrito daqui pra frente.
- Identificadores (nomes de variáveis, funções, classes, arquivos) continuam em inglês, seguindo a convenção já usada no código.
- Documentação (README, ADRs, roadmap) segue como está sendo escrita hoje, a não ser que o usuário peça o contrário.
