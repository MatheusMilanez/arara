# ARARA
## Identidade Visual + Prompts para Interface

**Projeto:** ARARA
**Categoria:** Open Source Distributed Indexing Platform
**Posicionamento:** Infraestrutura aberta de descoberta e indexação
**Abordagem:** AI First
**Mercado inicial:** Brasil
**Status:** Definição de identidade visual e protótipo inicial

---

# 1. CONCEITO DA MARCA

## 1.1 O que é o ARARA

ARARA é uma plataforma open source de indexação distribuída, inicialmente focada na descoberta, organização e consulta de dados, documentos e recursos abertos brasileiros.

A plataforma deverá permitir que diferentes fontes sejam descobertas e indexadas através de uma infraestrutura distribuída, preparada para evolução futura em direção a uma rede aberta de nós.

O produto deve transmitir:

- tecnologia;
- confiança;
- inteligência;
- simplicidade;
- abertura;
- distribuição;
- conhecimento;
- identidade brasileira.

---

# 2. POSICIONAMENTO VISUAL

O princípio central da identidade é:

> **Simple outside. Complex inside.**

Em português:

> **Simples para quem usa. Poderoso por baixo.**

A interface não deve parecer um painel de infraestrutura.

O usuário não precisa enxergar:

- shards;
- workers;
- replicas;
- queues;
- nodes;
- distributed processing;
- indexing pipelines.

Esses elementos pertencem à infraestrutura.

Para o usuário final, o ARARA deve ser extremamente simples:

```text
                    ARARA

            O que você quer descobrir?

        ┌───────────────────────────────┐
        │ 🔍 Pesquisar no ARARA         │
        └───────────────────────────────┘

               Pesquisar   Explorar
```

---

# 3. REFERÊNCIA DE EXPERIÊNCIA

A experiência inicial deve seguir a filosofia dos grandes mecanismos de busca:

- extremamente limpa;
- foco absoluto na busca;
- poucos elementos;
- muito espaço negativo;
- navegação discreta;
- resultados rápidos;
- hierarquia visual clara.

O ARARA pode ter uma experiência semelhante à simplicidade de um buscador tradicional, mas **não deve copiar visualmente Google ou qualquer outra marca**.

A identidade deve ser própria.

---

# 4. PERSONALIDADE

O ARARA deve parecer:

### Inteligente

A plataforma possui uma camada de IA capaz de interpretar consultas e relacionar informações.

### Confiável

Os resultados devem mostrar claramente suas fontes.

### Aberta

Open source, transparente e orientada à colaboração.

### Brasileira

A identidade brasileira deve ser sofisticada, não caricata.

### Técnica

A plataforma é infraestrutura de tecnologia.

### Minimalista

Complexidade deve existir no backend, não na interface.

---

# 7. LOGO

O logo deverá utilizar:

**ARARA**

com símbolo independente.

O símbolo deve ser uma abstração geométrica de uma arara.

Evitar:

- ilustração realista;
- mascote infantil;
- excesso de detalhes;
- aparência de empresa ambiental;
- estética de zoológico;
- bandeira brasileira literal.

O símbolo deve funcionar em:

```text
ARARA
```

```text
[ símbolo ] ARARA
```

```text
[ símbolo ]
```

O símbolo isolado deverá ser adequado para favicon e avatar do GitHub.

---

# 8. ELEMENTO GRÁFICO DA REDE

Um elemento recorrente da identidade será o conceito de **nós distribuídos**.

Representação:

```text
       ●
       │
   ●───●───●
       │
       ●
```

Os pontos representam:

- nós;
- fontes;
- dados;
- relações;
- infraestrutura distribuída.

Esse elemento pode aparecer de forma muito discreta em:

- animações;
- loading;
- página institucional;
- documentação;
- dashboards;
- página de status.

Não utilizar redes gigantes ou complexas na home.

---

# 9. EXPERIÊNCIA DA HOME

A home deve ter um objetivo único:

> **Levar o usuário à descoberta.**

Estrutura:

```text
Header mínimo

              ARARA

      Indexação aberta do Brasil

        [ campo de busca ]

       [ Pesquisar ] [ Explorar ]



      métricas discretas da rede



      Open Source · Distributed · AI First
```

Não utilizar:

- cards gigantes;
- dashboard;
- carrossel;
- excesso de ícones;
- menus complexos;
- banners;
- anúncios;
- chamadas comerciais.

---

Depois que o usuário pesquisar, a interface deve mudar de composição.

```text
População residente por município

Dataset · CSV · API

```

---

# 11. IA NA BUSCA

O ARARA é AI First.

A IA não deve aparecer simplesmente como um chatbot separado.

Ela deve estar integrada à experiência de busca.

Exemplo:

```text
ARARA ✦ AI

Sua busca envolve dados de população,
municípios e saúde pública.

Encontrei informações relacionadas em:

• IBGE
• Dados Abertos
• fontes estaduais
• fontes acadêmicas
```

A resposta gerada por IA deverá sempre possuir:

- fontes;
- referências;
- indicação de origem;
- possibilidade de abrir o documento original.

A IA nunca deve criar a percepção de que a informação surgiu "do nada".

## PROMPT 01 — ARARA HOME

Crie a interface inicial de uma plataforma chamada **ARARA**.

O ARARA é uma plataforma brasileira, open source e AI First de descoberta e indexação distribuída de dados, documentos e recursos digitais.

A interface deve transmitir a ideia:

**"Simple outside. Complex inside."**

O usuário final deve enxergar uma experiência extremamente simples, semelhante à filosofia de um grande mecanismo de busca, mas com identidade visual própria e sem copiar Google.

### Objetivo da tela

A única ação principal da página é permitir que o usuário pesquise algo.

### Direção visual

Crie uma interface:

- minimalista;
- premium;
- tecnológica;
- profissional;
- extremamente limpa;
- com muito espaço negativo;
- inspirada em produtos de infraestrutura tecnológica modernos;
- com identidade brasileira sofisticada;
- sem aparência governamental;
- sem estética infantil;
- sem excesso de elementos.

### Cores

Use:

- azul profundo `#0B1F33` como cor principal;
- amarelo `#F5C518` como accent;
- verde `#1E8E5A` apenas para estados positivos;
- fundo `#FAFAF7`;
- texto `#111111`;
- texto secundário `#6B7280`;
- bordas `#E5E7EB`.

### Logo

Criar um logotipo textual "ARARA" acompanhado de um símbolo geométrico minimalista inspirado em uma arara.

O símbolo deve ser abstrato e moderno.

Não criar uma arara realista.

Não usar bandeira brasileira.

Não utilizar elementos folclóricos exagerados.

### Layout

Desktop-first.

No topo, criar uma navegação extremamente discreta:

ARARA à esquerda.

No lado direito:

- Explorar
- Sobre
- GitHub
- Status

Não criar um mega menu.

No centro da tela:

ARARA

Abaixo:

"Descubra o conhecimento brasileiro."

Abaixo:

um grande campo de pesquisa horizontal com ícone de busca.

Placeholder:

"O que você quer descobrir?"

Abaixo do campo:

botão primário:

"Pesquisar"

botão secundário:

"Explorar"

### Elementos secundários

Na parte inferior central, apresentar discretamente:

"Open Source · Distributed · AI First"

Também pode apresentar pequenas métricas:

"18.2M recursos indexados"

"847 nós ativos"

"37K fontes"

Essas métricas são apenas placeholders visuais para o protótipo e devem ser claramente estruturadas para receber dados reais posteriormente.

### IA

O campo de pesquisa pode possuir um pequeno indicador:

"✦ ARARA AI"

Esse indicador deve ser extremamente discreto.

Não criar chatbot.

Não criar janela de conversa.

A IA deve parecer parte natural do mecanismo de busca.

### Animação

Adicionar microinteração extremamente sutil no carregamento.

Pequenos pontos amarelos podem aparecer formando uma pequena estrutura de rede e desaparecer suavemente.

A animação deve durar aproximadamente 1 segundo.

Não criar splash screen.

### Resultado esperado

A primeira impressão deve ser:

"Este é um mecanismo de descoberta extremamente sofisticado."

Não deve parecer um dashboard.

Não deve parecer uma landing page SaaS.

Não deve parecer um clone do Google.

Deve parecer uma nova infraestrutura de busca brasileira, open source e tecnologicamente avançada.

Crie o protótipo completo da tela utilizando componentes reutilizáveis, design system consistente, responsividade e atenção extrema à tipografia, espaçamento, hierarquia visual e acessibilidade.

No topo da área de resultados, criar uma seção especial e muito elegante:

IBGE

Dados Abertos

A interface deve dar grande importância à origem dos dados.

Cada resultado deve mostrar claramente:

- fonte;
- tipo;
- atualização;
- origem;
- link para recurso original.

O usuário deve perceber que o ARARA não é a fonte original.

O ARARA indexa e organiza informações provenientes de fontes externas.

### Visual

Manter:

- fundo `#FAFAF7`;
- azul `#0B1F33`;
- amarelo `#F5C518`;
- verde `#1E8E5A`;
- texto `#111111`;

- bordas `#E5E7EB`.

Evitar cards pesados.

Evitar sombras exageradas.

Evitar gradientes.

Evitar glassmorphism.

Evitar estética de dashboard.

Evitar excesso de ícones.

### Interações

Criar estados para:

- hover;
- foco;
- resultado selecionado;
- salvar;
- abrir fonte;
- filtro ativo.

Adicionar microinterações suaves.

Nada chamativo.

### Responsividade

No mobile:

- esconder o painel lateral;
- transformar filtros em scroll horizontal;
- manter a busca no topo;
- resultados ocupando toda a largura;
- preservar hierarquia visual.

### Resultado esperado

A página deve parecer um mecanismo de busca profissional de próxima geração.

A experiência deve comunicar:

**"ARARA encontrou informações em diferentes fontes e organizou tudo para mim."**

A interface deve continuar simples, mas demonstrar mais inteligência do que um mecanismo de busca tradicional.

Manter consistência absoluta com a Home do ARARA.

# 18. REGRA DE DESIGN DO PROJETO

Todas as próximas telas do ARARA deverão seguir uma regra:

> **Não adicionar uma interface apenas porque existe uma funcionalidade.**

Antes de criar qualquer componente, perguntar:

1. O usuário precisa disso?
2. Essa informação precisa aparecer agora?
3. Existe uma maneira mais simples?
4. Isso melhora a descoberta?
5. Isso reforça a confiança?
6. Isso mantém a identidade do ARARA?

Se a resposta for não, o elemento não deve existir.

---

# 19. PRINCÍPIO FINAL

O ARARA deve ter uma aparência simples o suficiente para uma pessoa comum utilizar e uma profundidade técnica suficiente para um engenheiro perceber que existe uma infraestrutura distribuída extremamente complexa por trás da interface.

**Interface: simples.**

**Experiência: inteligente.**

**Infraestrutura: distribuída.**

**Dados: abertos.**

**IA: integrada.**

**Código: open source.**

**Identidade: brasileira.**
